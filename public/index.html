API Documentation

Toys API

Method Path Info Parameters / Request Body
GET /toys Returns a list of toys according to the query parameters you use.
  • skip: the number of toys to skip before starting to return results. (default: 0)
    https://mongo-project-nu.vercel.app/toys?skip=5
GET /toys/search Returns the list of toys that match the search query, either by name or description.
  • s: the search query to match against toy names or descriptions.
    https://mongo-project-nu.vercel.app/toys/search?s=yoyo
GET /toys/category/:catName Returns the list of toys that belong to the specified category.
  • catName: the name of the category to filter toys by.
    https://mongo-project-nu.vercel.app/toys/category/arts
GET /toys/single/:id Returns a single toy item by its ID.
  • id: the ID of the toy to retrieve.
    https://mongo-project-nu.vercel.app/toys/single/6a3120f6f1369f8cba8309d0
GET /toys/count Returns the total count of toys in the collection.
  • No body required for this request. Example: https://mongo-project-nu.vercel.app/toys/count
POST /toys Adds a new item to the toys collection. Requires authentication. Send a valid authentication token in the request headers and provide the toy details as a JSON request body.
  • JSON body with toy details in the following format: 
    {
  "name": "String",
  "info": "String",
  "category": "String",
  "img_url": "String",
  "price": "Number"
}
PUT /toys/:id Updates an existing toy by its ID. Requires authentication and a JSON request body containing the updated toy details.
  • id: the ID of the toy to update.
  • JSON body with updated toy details in the following format: 
    {
  "name": "String",
  "info": "String",
  "category": "String",
  "img_url": "String",
  "price": "Number"
}
DELETE /toys/:id Deletes an existing toy by its ID. Requires authentication.
  • id: the ID of the toy to delete.

Users API

Method Path Info Parameters / Request Body
GET /users Test endpoint to check if the server is running.
  • No parameters or request body.
GET /users/userInfo Returns information about the currently authenticated user. Requires a valid authentication token.
  • No parameters or request body.
POST /users Creates a new user.
  • JSON body with user details in the following format: 
    {
  "name": "String",
  "email": "String",
  "password": "String",
  "role": "String" (admin/user, default: user)
}
POST /users/login Log-in as an existing user.
  • JSON body with user credentials in the following format: 
    {
  "email": "String",
  "password": "String"
}
