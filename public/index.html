TOYS DOCS

Method Path Info Body
GET /toys You have the option to get the items from toys collection , ?s= No body
GET /toys/single/:id You have the option to get a single item from the toys collection by its ID No body
GET /toys/search You have the option to get the items from toys collection , ?s= No body
GET /toys/category/:catName You have the option to get the items from toys collection by category No body
GET /toys/count You have the option to get the count of items from the toys collection No body
POST /toys You have the option to add a new item to the toys collection JSON body with toy details
PUT /toys/:id You have the option to update an existing item in the toys collection by its ID JSON body with updated toy details
DELETE /toys/:id You have the option to delete an existing item from the toys collection by its ID No body

USERS DOCS

Method Path Info Body
GET /users Since no-one can access user data without proper authorization, this endpoint returns the list of users No body
GET /users/userInfo You have the option to get the information of the currently authenticated user No body
POST /users/register You have the option to register a new user JSON body with user details
POST /users/login You have the option to log in an existing user JSON body with user credentials
